# Aman Singh — Personal Portfolio Website

A simple and semantic **Personal Portfolio Website** built using **HTML5**.

This project was created as a practical assignment to learn and demonstrate the fundamentals of HTML, including semantic structure, headings, paragraphs, links, images, lists, tables, forms, buttons, and navigation.

---

## 🚀 Project Overview

This portfolio website introduces **Aman Singh**, a Full Stack Developer and AI Enthusiast.

The website contains information about:

* Personal introduction
* About Me
* Educational qualifications
* Technical and other skills
* Projects
* Contact information
* Contact form
* GitHub profile

The project focuses mainly on **HTML5 fundamentals** without using CSS or JavaScript.

## 📚 HTML Concepts Learned

This project demonstrates the following HTML5 concepts.

### 1. HTML5 Document Structure

Used:

```html
<!DOCTYPE html>
<html>
<head>
<body>
```

### 2. Semantic HTML

Semantic elements used in the project include:

```html
<header>
<nav>
<main>
<section>
<article>
<footer>
```

These elements help organize the webpage into meaningful sections.

### 3. Headings and Paragraphs

Different heading levels are used to structure the content:

```html
<h1>
<h2>
<h3>
```

Paragraphs are created using:

```html
<p>
```

### 4. Links

Internal navigation links:

```html
<a href="#home">Home</a>
<a href="#about">About</a>
<a href="#projects">Projects</a>
```

External links are also used for GitHub.

### 5. Images

The Home section contains a profile image using:

```html
<img>
```

The `alt` attribute is also used to provide alternative text.

### 6. Lists

Unordered lists:

```html
<ul>
<li>HTML5</li>
<li>CSS3</li>
</ul>
```

Ordered lists:

```html
<ol>
<li>Problem Solving</li>
<li>Teamwork</li>
</ol>
```

### 7. Tables

Educational information is displayed using:

```html
<table>
<thead>
<tbody>
<tr>
<th>
<td>
```

A table caption is also included using:

```html
<caption>
```

### 8. Forms

The Contact section demonstrates HTML forms using:

```html
<form>
<label>
<input>
<textarea>
<button>
```

Different input types are used:

```html
type="text"
type="email"
type="tel"
```

### 9. Form Validation

Basic browser-level validation is implemented using:

```html
required
```

and:

```html
type="email"
```

### 10. Buttons

The form contains:

```html
<button type="submit">
<button type="reset">
```

# 📝 My Task Manager

A simple and responsive **Task Management Application** built with **HTML, CSS and Vanilla JavaScript**.

This project was developed as part of my **JavaScript Internship Assignment** to practice core JavaScript concepts such as DOM manipulation, events, arrays, objects, functions, conditions and LocalStorage.

---

## 🚀 Features

### Task Management
- ➕ Add new tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- ✅ Mark tasks as completed
- 🔄 Mark completed tasks as active again

### Task Organization
- 🔎 Search tasks
- 📌 Filter by task status
- 🎯 Filter by priority
- 📂 Categorize tasks
- 📅 Add due dates
- 🚦 Set task priority

### Additional Features
- 📊 Task statistics
- 🧹 Clear completed tasks
- 🗑️ Clear all tasks
- 🌙 Dark / Light mode
- 💾 LocalStorage support
- 📱 Responsive design
